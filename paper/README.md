# Paper assets

`figures/` contains exported manuscript figures and their provenance sidecars.
Keep a figure and its provenance together. These are development illustrations,
not new independent test results.

Start writing from [the paper handoff](../docs/paper/PAPER_WRITING_HANDOFF.md).
Follow [the experiment protocol](../docs/paper/PAPER_EXPERIMENT_PROTOCOL.md)
for new results. Recorded inputs stay in `data/flight_batches/`; fitted models,
original predictions and computation logs stay in `runs/`.
