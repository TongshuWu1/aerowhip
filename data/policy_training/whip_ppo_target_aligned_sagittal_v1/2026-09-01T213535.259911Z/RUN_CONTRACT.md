# Task-whip PPO reward study — 7-second episode

Training uses the canonical settled initial state. Every 10,240 episodes, the deterministic policy is evaluated on the same 64 held-out, physically varied, physically propagated initial states. Training and validation both use the production UAV + causal residual + 12-node DDER simulator. The policy action is target-aligned forward/backward and vertical acceleration plus pitch rate. The reported success requires the single first target entry to be tip-first with speed and direction; entry timestep is diagnostic only and numerical UAV limits are smooth costs. Speed-shaping credit is capped at 4 m/s. The dense speed-shaping reference is attachment_relative; hard success still uses true world-frame tip velocity. No CEM, protected data, or hardware is used. A STOP_REQUESTED file causes a checkpointed cooperative stop.
